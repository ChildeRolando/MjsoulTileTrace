有效牌，不只是“有几种”

今天只取得一个胜利：面对候选舍牌，先保留最低向听，再把有效牌的“种类”换算成牌山中实际可能摸到的“剩余枚数”。

两个量，两个问题

有效牌种哪些牌摸入后会让向听数下降？这是一个不重复的集合。
剩余枚数这些牌在未知区域最多还有几枚？这是实际进张机会。
先向听，后枚数；先列牌种，再扣已知牌。

向听数是第一层筛选。某一打即使留下很多看似相关的牌，只要它让手牌从二向听退成三向听，就不应和保持二向听的候选直接比枚数。

完整手算一次

手牌为 123m 456m 789p 23s 55z 9s。其中 m/p/s/z 分别表示万、筒、索、字牌。

候选舍牌
舍牌后向听数
有效牌集合
扣除已知牌
总剩余枚数

切 9s 后保留三个完成面子、一个雀头和 23s 搭子，仍是一向听。完成最后面子的牌为 {1s, 4s}。

1s：4 − 0 − 0 = 4枚
4s：4 − 0 − 0 = 4枚
合计：2种、8枚

若切掉 2s 或 3s，现成搭子被破坏，手牌退为二向听。即使剩余孤立牌存在大量“将来可能有用”的邻接牌，也不能在本层胜过切 9s。

轮到你：三次检索

不要凭“看起来多”作答。每题都说出自己正在比较的是向听数、有效牌种，还是剩余枚数。

01｜种类不等于枚数

某候选舍牌保持最低向听，有效牌为 {2m, 5m, 8p}；未知区域分别还剩 3、4、3 枚。正确描述是？

02｜先扣手里的牌

3s 是有效牌；你手中已经有两枚，牌河与副露区没有出现。它最多还剩几枚？

03｜向听优先于枚数

候选 A 保持一向听，有效牌 8 枚；候选 B 退成二向听，但有 15 枚牌能改善牌形。纯牌效率下先选哪一个？

把今天压缩成四步

枚举候选舍牌 → 保持最低向听 → 列出不重复的有效牌 → 扣掉手牌和公开牌。
