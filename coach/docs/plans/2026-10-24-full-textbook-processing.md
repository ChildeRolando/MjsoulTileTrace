## 轻量 MCP 装配

保留 `TextbookKnowledgePort` →原生 MCP→`ArenaRunnerTool` 的模块边界，生产默认配置不变。工具为：

1. `catalog_textbook`：章节目录分页；指定 `chapterId` 后列出章内阅读单元。`nextOffset` 指向下一页。
2. `search_textbook`：小块关键词检索，返回定位预览；`nextOffset` 可以继续结果。预览不授予引用。
3. `read_textbook`：展开完整论证。较长论证分块传输，跟随 `nextBlockOffset` 直到 null，再按块序拼接。任何部分响应的 `completeArgument` 都为 false，包括尾段。
4. `view_textbook_figure`：原 PNG 与独立校对后的完整文字牌例。Arena 的文字通道不冒充看过原图。

每次结果仍限 16 KiB，给 Arena 外层保留 1500 字节。分页按实际字节预算调整条数，并返回真正的后续偏移，不静默截掉章节/论证。完整段落只为传输作可逆切块，所有片段拼接逐字符等于入库正文。

Arena 在同一运行内记录已经读取的论证块；必须覆盖该单元从起点到末尾的全部块才授予正文引用。跳读尾页不能获得完整论证引用，另一运行不能继承读取范围。牌例的完整核对转录可以独立引用。

章节索引一次聚合，文本分词在加载时建立；不引入图谱、向量库或新服务。图片按需读磁盘，每次检查路径范围、PNG 格式和 SHA，不把全部图像驻留内存。加载目录由宿主固定，模型只能使用登记 ID；没有教材写入 MCP。

```powershell
node scripts/textbook-processing/publish-textbooks.mjs E:/AgentData/Coach/knowledge/processing production/APPROVED_RUN/candidates E:/AgentData/Coach/knowledge/processing/integration/chapter-map.json E:/AgentData/Coach/knowledge/review
```

`APPROVED_RUN` 是占位符，只能替换为冻结且全部页审校通过的制作批次，不能指向已拒收的 Luna v4 稿。校准页通过不足以执行该全量命令。

修订页和已通过校准页可通过第五个位置参数传入候选选择清单：`{ "schema": "coach-textbook-candidate-selection/1", "pages": [{ "sourceId": "nemata-jp", "page": 98, "candidatePath": "production/sol-high/candidates/nemata-jp/page-0098.json", "candidateSha256": "完整候选文件的 SHA-256" }] }`。每页仍重新验证独立审校、源材料和候选字节；不复制修改旧批次 manifest。当前四页清单为 `processing/integration/calibration-candidate-selection.json`，全量制作可复用并排除这四页，避免重复付费。修订页在单独冻结 run 中产生，再通过显式清单选入。

发布收据区分直接通过、逐项源图裁决和传输分类恢复，保留原 `modelChecks`、裁决证据及原始失败调用身份，不改写成全部模型一次通过。

发布器先在同一目录内完整构建/验证 staging，再安装内容寻址图片，最后替换正文、索引和 MCP manifest。`publication-in-progress.json` 记录这一小组固定文件的期望哈希。中断导致的混合 manifest 会被 MCP 的正文身份检查拒绝；恢复不重跑模型：

## 新增场景关注点（显式装配）

原 18 条 `scene-patterns/v1` 及原实验记录保持身份。新增 `scene-patterns-extended/v1` 只有通过 `sceneStudy.enableExtendedPatterns=true` 才注入，默认关闭。

| ID | 确定事实触发 | 研究问题 |
|---|---|---|
| P19 | 两候选向听不同，较慢候选保有宝牌更多 | 退向听保宝的价值/速度条件。宝牌数不是确定打点，不跨向听直接比较进张数。 |
| P20 | 听牌候选等待非空，所有等待未见枚数已知且为零 | 枯死等待、换听与改良。未见枚数不是活牌山枚数。 |
| P21 | 有公开威胁，完整合法弃牌候选全部至少二向听 | 慢手押引与弃和。裸候选数组/候选子集无完整性证明时资料不足。 |
| P22 | 两候选保留的役牌对子集合不同 | 拆留役牌对子的速度、役与防守条件，不推荐碰牌动作。 |

这些是检索工程触发条件，不是教材适用边界。均可输出资料不足，均引用候选事实，不读取实际选择、对手暗手、未来或 Mortal 标签。P21 仅接受 Arena 已验证的完整合法候选引用集合证明。

全量教材可主动检索平和、断幺、三色、一通、国士、复杂待牌、吃碰立直杠、训练方法等，但目前模式事实没有充分的役种分解、改良分布、和了役/得点及行动前后比较能力。这些教材的收录不表示新增行动推理已启用，也不表示全场景效果已验证。
