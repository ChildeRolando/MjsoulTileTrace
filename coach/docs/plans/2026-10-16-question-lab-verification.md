# Question Lab 变更控制与本地验收

## Scope

实现独立离线研究包：严格配置、实体牌分配、原生 Board 历史构造、canonical 可见投影、
完整 Mortal 标注、逐题可恢复档案、分组 SVM、合法主动补样和自包含牌面报告。
以 `2468e92` 主线为集成基线；本次范围含 PR #63 审核与合并，不含生产部署或启用。
合并状态与落点以 PR #63 的最终记录为准。

## Locality

- contracts：版本化实验/样本/标注/边界协议与 `synthetic` 来源，拒绝未知字段与谓词。
- mortal-runtime：固定上游 Board 的受控 wrapper、无权重构造进程及其内容身份；不另写规则。
- reasoning：复用现有公共快照、未行动决策、规则与评分绑定、helper 事实接口；增加显式研究评分
  投影，唯一行动也保留真实 Q，生产入口仍要求至少两个行动。
- question-lab：只拥有研究编排和档案；不写 ReviewSession，不被生产消费者依赖。
- 现有架构检查器、package-import smoke、构建脚本、ADR 与不变量同步扩展。

架构检查：8 包、545 文件、2683 imports、0 violation。所有跨包消费走公共 exports。

## Invariants / Traceability

INV-001/002/004/006/007/009 沿用严格契约、完整规则集合、事实与标签分离、内容身份与重放。
新增 INV-014：私有全知构造见证和可见样本分离、同源分组隔离、留出测试禁止反馈到补样。
配置/construct/projection/groups/archive/native 回归及独立 Python 测试保护这些边界，未削弱既有断言。

原生规则是合法性权威；helper 的打点是版本化启发式；Mortal Q 与最终选择是模型标签。
每题保存原生见证、可见历史、事实、完整行动、标签及生产者哈希；恢复核对身份和内容。
研究启发式取 12 位有效数字，原始 helper 输出另存 SHA；防止上游浮点末位漂移改变题目身份。
同进程验证复用仍每次核对完整源文件哈希，修改后重验；结果副本不暴露缓存对象。

## Replaceability / Semantic Load

新增 question-lab 隔离实验分布、采样预算与学习依赖。若并入生产 reasoning，会把研究归档、
scikit-learn 和模型选择策略带入复盘路径；生产 snapshot/helper/规则权威没有合适的档案所有权。
构造接口留在现有 native owner；新增契约进入原有 contracts；未引入第二套规则或治理机制。
替换学习算法只影响 lab 的独立进程协议和版本；替换规则/模型仍须明确新的生产者身份与验收。

## Recoverability

成功样本与标签逐条原子落盘，单写者锁、串行替换和有限 Windows 文件占用重试保护档案。
固定种子/配置/生产者复现，native 中断恢复测试确认已有真实推理不重复，完成样本身份一致。
非法库存、动作或历史在构造/原生验证层拒绝；预算耗尽只表示搜索未完成，不表示已证明无解。
