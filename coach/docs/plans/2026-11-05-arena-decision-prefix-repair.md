# Arena 来源前缀隔离修复

## 范围和责任

MJAI 研究适配器原先为前缀证明构建整个牌谱的 canonical 事件流，导致所选决策之后的事件可以令当前重放失败。本改动按来源 ordinal 解析并映射至触发事件，交给既有 reducer 的流也以该事件结束；不伪造终局。完整来源字节摘要仍绑定原件，证明中的 stream 摘要绑定实际前缀流。全场入口仍按原要求解析、验证完整牌谱。

## 变更控制

- Locality：改动 MJAI corpus 的映射及身份前缀验证、对应测试和此说明；使用已有 JSON 流解析依赖处理数组和封装格式。没有修改 contracts、reasoning 或规则引擎。
- Invariants：INV-003/009 的协议边界和唯一 canonical 事实来源由既有架构检查及 corpus 测试保护；INV-004 的窗口、候选和证据绑定由既有前缀投影校验及定向反例保护；INV-013 的未来事件和隐藏牌隔离由定向变异测试及 Arena 现有行为测试保护。全场验证未放宽。
- Traceability：原始来源摘要、真实输入前缀流摘要、当前局原始及 canonical 前缀摘要和位置证据保持明确绑定；来源适配器仍是可信边界。
- Replaceability：只扩展既有来源适配器；reasoning 不依赖 MJAI，libriichi 仍是唯一合法动作来源。
- Recoverability：缺少触发事件、损坏的当前前缀和伪造证据在本地失败；坏后缀不干扰先前决策。针对失败案例的独立资料和验证记录由研究档案保存。
- Semantic load：无新架构抽象；局部能力折入既有前缀入口和身份校验。
- Verification：执行的构建、针对性测试、架构检查及真实案例规则核对以固定提交的工程收据为准；模型、Mortal 评分均不属于本次验证。
