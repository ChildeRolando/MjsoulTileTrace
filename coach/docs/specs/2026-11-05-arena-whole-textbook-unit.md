# Whole textbook unit Arena intervention

The opt-in `textbookInputBudget` enables a 256 KiB decision input limit in both matched decision arms; the runner requires that exact explicit limit. `wholeUnitFacts` additionally enables the selected textbook packet. Both require the existing legal-candidate and basic-calculation modules, direct tile/red output, no tools, mixed helper, other fact modules, hints, teaching retrieval, comparison, or explanation. Legacy paths retain their 64 KiB request limit. The selector has a separate explicit 128 KiB isolated request profile. Output, token-accounting and time limits are unchanged.

`createWholeUnitLibrary` verifies the complete frozen index digest and every unit content digest, and retains all 240 catalog entries. It accepts no reconstructed, cropped, untrusted, or modified library. The catalog identifies the 237 instruction and three non-selectable navigation units. `assembleWholeUnitSelector` combines the same visible position, full candidates and basic calculations with title/chapter/role/length metadata only; its strict response schema accepts one instruction unit ID or null. `runWholeUnitSelector` executes one existing provider request; it retains status, usage, elapsed time and raw output for the selector ledger. No raw selector output or rationale is part of the decision packet.

`createWholeUnitFacts` creates a case-bound selected, none, or unavailable packet. Selected content is the complete frozen unit with source and content digest; assembler checks it against the trusted in-process library. `none` is a valid null selection; `unavailable` distinguishes invalid output and provider failure. Selector and decision dispatch ordering, durable no-retry/resume, fixed selections and ledger ownership remain the experiment orchestrator's responsibility; no model call is made by assembly.
