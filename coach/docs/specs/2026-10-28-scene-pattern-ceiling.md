# 场景模式集与直接规则匹配 RAG 上限评测 v1

用户于2026-10-28批准完整执行。独立离线研究，不切换教材正式库、不改生产默认行为。

## 固定设计

固定232章/240单元教材快照：`accepted-content-preview-2026-10-27T19-21-37-757Z`。
完整复制正文、索引、复核回执和5128张图片，按文件内容哈希绑定；不跟随移动的 current 指针。
使用现有 libriichi 纯弃牌筛选、可见事实投影、原生 Mortal 首选标签、完整候选和实体等价评分。
每场只选一个固定随机座位和一个合格窗口；不同阶段及旧研究来源按规范牌谱与来源哈希隔离。
开发160题（120自然/40挑战）、正式800题（600自然/200挑战）、冒烟20题；不足拒绝运行。

主模型 gpt-6.1-sol/high；实用模型 gpt-6-luna/max。固定模型名不保证远端模型权重不可变。
核心各题单次请求、相同生成提示与公开事实：A无模式无教材，B仅最终模式，C仅事实词项检索，
D最终模式和直接匹配，V0为新教材适配后的18模式/原词项排序；旧40卡结果不是V0。
没有生成时自主查询或隐含第二轮请求。每题至多6个完整资料单元，总计6000字符。

## 三轮优化及诊断

在开发集依次评估V0、r1（教材别名与标题加权）、r2（威胁/点况/振听优先及主题覆盖）、
r3（兼顾路线、无明显威胁的效率关注、资料不足提醒）。这些候选预先写在冻结代码中，
不根据正式答案产生新规则；开发自然集全尝试一致率选版，同分依次按平均Q差、规则数、形成顺序。
X01/X02必须绑定实际教材章节；X03仅提醒事实未知，不能冒充新的教材打法规则。
模式不改合法候选，不调用Mortal。选版记录写入后，正式运行才可启动。

200题资料优选O（150自然/50挑战）：独立上下文先按完整目录选至多4章，再读取可完整交付正文
选段，最后按与D相同条件生成。选材最多两次调用、输入正文最多12000字符、交付仍至多6000字符。
不裁剪完整论证；超预算、空选择、失败及仅有未查看图片均明确记录。O是受预算约束的AI选材对照，
不是专家真值或理论上限。实用复验预选100题（75/25），运行A/V0/D/O；稳定性50题（40/10），
A/D再各生成一次，禁止挑选多次答案中的最优者。

## 预算与恢复

按模型请求前fsync的hash链账本计数：开发800、正式4000、O600、实用400、稳定性100、冒烟100，
总额6000。失败、超时及选材请求占额度；意图已归档但结果缺失的请求按中断保留，绝不补发。
CLI内部可观察的reconnect另报；账本计量的是实验provider请求，无法声称服务端内部请求数。
同一目录只能有一个运行进程；恢复先核对原PID已经不存在。执行代码、输入及教材变化拒绝续跑。
采用现有Arena实际单轮120秒上限、两并发；不把外层更长时间宣称为底层已经支持。

全部980题标签绑定成功后才允许生成。冒烟成功率至少95%、非法提交/候选错绑/泄露为零。
第一批10题×5组；最多保留另一批独立10题做修复复验，两个批次都计入100次。
未过闸门停止本版本，不继续消耗正式额度。正式结果不自动重试、不换题、不提前发布组间胜负。
工程修复后只允许在开发尚未开始、第一批最多50次且没有通过冒烟时执行 `freeze --repair true`；
旧冻结身份另存engineering-revisions，原账本和失败不动，再运行smoke2。不允许以此修改数据或教材。

## 指标和结论

主指标自然集匹配数/600，失败保留；主比较D-A，次要D-V0/D-B/D-C用Holm校正。
按独立牌谱配对bootstrap 2000次，95%区间；另报条件一致率、平均/90分位Q差、失败、覆盖、
空结果、token和耗时。未知用量不补零，缓存输入不重复相加。挑战、模式分层和重复生成仅诊断。
继续投入标准：自然集增益至少5个百分点、区间下界>0、成功率>=95%；实用token目标1.3倍。
不能将未显著、AI判读、候选覆盖或Mortal一致率分别改写成无效、专家真值或教学质量证明。

资料库全量索引，但超过6000字符的整个教学单元不直接交付。v1目前43个超预算单元、3个导航单元。
这部分是明确的研究实现限制；不能把未交付推导成教材没有覆盖。后续改为章节内论证窗口需要新版本。
