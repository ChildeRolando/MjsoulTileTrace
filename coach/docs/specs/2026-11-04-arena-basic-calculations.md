# Arena basic calculation module

The optional static module extends Arena's existing modular assembly and fact-engine boundary. It derives one result for every offered canonical discard in the original order from the bound decision-time facts using `projectCandidate`, `analyzeHand13`, and `validateHand13Result`. It exposes only shanten, effective tiles and unseen copies, and dora count. Unseen copies include tiles in unknown locations and are neither live-wall counts nor probabilities. Failed and unavailable calculations remain explicit. No action ranking, estimate, model output, label, or teaching material enters this module.

The existing raw and MCP paths retain their behavior. A separate opt-in configuration selects this module, with no model-callable tools. Assembly validates exact candidate order and strict output shape. It uses standard hand13 mode, since efficiency mode does not compute dora; missing indicators remain unknown. Engine identity and module version provide provenance; size and run budgets remain unchanged. Coverage, failure, raw regression, red tiles, calls, and blind-boundary checks are verified before use. This is a basic subset, not the complete Coach helper.
