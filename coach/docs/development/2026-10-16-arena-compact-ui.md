# Arena 单屏布局验收

## 范围

五个既有页面沿用统一侧栏和视觉样式，缩短重复说明，使用分页、内容分区和折叠收纳。仅改变展示；题库、模型输入、预算、评分口径、重跑调度和归档格式不变。

- 实验控制台：并排配置题库与方案，预算横条，当前任务步骤分页，题库预览切换到独立视图。
- 实验结果：按屏幕高度每页 2 或 3 条；查看详情时替换列表。一次选择一个案例，分为牌面、Mortal Top 10、模型与工具过程、运行归档。
- 错题集：每页 3 题；列表与详情互相切换。详情左侧保留计数、重跑与历史选择，右侧展示当前快照的分区。
- 模型与 API 配置：连接与预算双栏，补充说明折叠，保持独立页面。
- 模型运行配置：连接、提示词、MCP、RAG 四个章节切换；RAG 片段分页。
- 牌河每页两家，Mortal 评分每页五项，工具过程每页一个步骤。长原文保留每个字符，支持跳页与下载全文；整轮模型用量、缓存输入、Arena 请求／响应大小仍分别标识。

不以隐藏溢出或强制缩小整页字体实现单屏。较小移动窗口、浏览器放大，以及主动展开较长说明时保留文档自然滚动；没有嵌套滚动面板。

## 验证

- 浏览器实测 1366×768、1280×720：五个页面默认视图均无纵向或横向溢出。
- 375×812：五项主导航完整可见，无横向溢出或嵌套滚动；保留自然纵向阅读。
- 实验结果翻页；三案例实验切换案例且更新地址；Mortal 第 6–10 名、四家牌河的后两家均可访问。
- 逐步查看模型／工具记录，展开参数，翻页和直接输入页码；旧快照切换回 Off 运行后显示相应来源和决策。
- 配置四章节逐一检查；API 连接字段可展开，未保存或修改既有配置。
- 浏览器无脚本错误。现有 console、mistakes、presentation 测试 12/12 通过；前端模块语法检查、diff 检查通过。

证据位于工作区外 `review-loop-closeout-artifacts/2026-10-16-arena-compact-ui/`：`layout-checks.json`、`results.png`、`mistakes-list.png`、`mistake-detail.png`。
