# Coach 验收工作区接入 · 2026-10-14

## 范围与现有边界

将已确认的互动设计接入 Electron 验收界面：独立路由、牌桌与手牌、右侧教练、可滑动的动态分歧列表、明暗主题、已读记录和阅读位置恢复。复盘不再追加在主页下方。桌面默认窗口 1440×960；1920×1080 时牌桌所在内容列最多 860px。滚动区域隐藏滚动条，仍支持原生滑动、键盘和前后按钮。

必要修改仅位于 contracts 的显示 DTO、desktop 的现有 presenter、renderer、资源复制脚本和对应测试。窗口大小调整不改变隔离、沙箱、IPC 身份校验和本地导航限制。沿用既有雀魂登录、近期牌谱、链接导入、分析、保存、解说生成和服务配置接口，没有引入第二条分析或报告生成链路。

## 数据来源与约束

- 新 `board` 是 `KnownGameFacts` 的显示投影，经原有 detail DTO、IPC 与 preload 校验传递；不发送原始来源包、凭据、其他玩家暗手或内部文件路径。
- `board` 和列表的局面标签为可选显示字段，旧分析包继续通过既有复盘路径读取。缺失分数、本场、供托或摸牌保持未知；牌河长度标作“已打 N 张”，不伪称准确巡目。
- 手牌与当前摸牌分开传递；牌河、宝牌指示、副露、立直和点数来自保存的确定性事实。赤牌保留原标记。
- 时间轴复用原选择结果与顺序，条数取实际数组；UI 不截为 3 或 10，也不修改入选策略。快速切换以最新详情请求为准。
- 已读标记、主题和阅读位置是本机界面偏好，不修改分析包、解说报告或事实。
- 损进张与改良张已接入真实后台计算，口径、范围和失败语义见下节。自由追问尚未接入；保留现有真实解说生成，不显示虚假的聊天回复。
- 牌面 SVG 复用本仓库 `course/assets/tiles`。新增 0m/0p/0s 为对应五牌的赤标记变体，随应用打包；没有外部图片请求。
