# Arena 界面文案减量

五个页面统一删去侧栏编号与口号、重复面包屑、页头导语、装饰徽标和页脚。导航保留完整页面名称，内容区以标题、间距、表单分组和数据排列建立层级。成功加载后的轮询时间不再常驻，加载、错误和实验状态继续反馈。
