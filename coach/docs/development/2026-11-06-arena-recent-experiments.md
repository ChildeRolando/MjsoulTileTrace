# 最近研究归档与错题筛选

Arena 的研究目录继续只读索引 `research-sources.json` 指定的来源，不复制或修改实验结果，不重跑模型。

本轮核对 2026-11-05 的七项实验：五轴提示、用户五轴 V2、Helper 预测、框架与预测组合、精简参考、选择性查询基础计算、四家公开场面表示。新版统计报告、实验设置补全版和结果解读附页进入阅读器；预检与模拟仍默认隐藏。

新增 `selective-study-run-index/v1` 的逐题读取，按冻结排程摘要、输入摘要和案例身份关联结果与过程。历史对照按已有复用注册表或报告声明的历史结果摘要回到原研究；仅从已配置目录的目录项解析，校验逐题匹配、失败和选择一致，拒绝循环及错配。

逐题记录增加“只看错题”按钮。只纳入明确 `match: false` 且无执行失败的记录；保留原题号，取消筛选保留当前案例，切换分组保留筛选，无匹配项时禁用选择框并显示空态。

验证：48 项 Node 测试、15 项阅读器/归档测试通过；Arena UI 构建和架构检查通过。真实归档检查七项实验的首尾案例、错题及失败，共 71 条，均可恢复原始场面。浏览器确认公开场面组为 73/200 道错题、历史五轴组为 60/200，键盘切换与原题号保持正常。

本次没有全库模型重跑；已有缺失的 Mortal 推荐不补造。详细本地记录与截图保存在 `review-loop-closeout-artifacts/2026-11-06-arena-recent-experiments/`。
