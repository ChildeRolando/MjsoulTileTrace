# Arena 1920×1080 默认布局验收

本次调整接续 `2026-10-16-arena-compact-ui.md`，将主要设计视口从小窗口改为 1920×1080。宽度至少 1600、高度至少 950 时展开更多有效内容；较小窗口继续使用紧凑布局。仅改变展示，不改变实验配置、评分或归档。

## 页面变化

- 实验控制台：增加配置区间距，展开题库说明；当前任务下显示最近三次实验。题库预览取消手牌／四家场面的分标签，默认同屏展示。
- 实验结果：1080p 每页八条，较小窗口按高度显示二、三或五条；窗口变化自动调整分页。Mortal Top 10 在大屏同页显示十项，小窗口恢复五项分页。
- 错题集：扩大卡片牌面；大屏打开详情默认显示案例牌面，手牌、候选、四家牌河与副露同屏。小窗口牌河折叠并按两家分页，原文和历史仍可访问。
- 模型与 API 配置：表单最大宽度 1080px，居中保留左右空白，数字输入最大宽度 230px，避免拉长输入框。
- 模型运行配置：内容最大宽度 1280px，增加正文阅读密度，大屏默认展开全部运行预算；RAG 每页最多六个片段。

不强制每个页面等高；内容较少的配置页保留合理留白。不使用隐藏页面溢出来伪造单屏，主动展开长内容仍允许自然滚动。

## 验证

- 1920×1080：五页默认视图的文档高度均为 1080px；配置表单实测宽度为 1080px。
- 错题详情同时显示四家；题库第 51 题（南四局、原局决策 121）含较长牌河及副露，手牌和四家场面同屏且无需滚动。
- 实验列表每页八条，翻页可达剩余归档；Mortal 十项评分同屏。1366×768 列表恢复三条，评分恢复五项；牌河随窗口缩小折叠。
- 浏览器未记录脚本错误；console、mistakes、presentation 现有测试 12/12 通过。前端模块语法检查和 diff 检查通过。
- 使用既有归档验收，未新增模型实验，未更改 API 配置。静态文件刷新即可生效，无需重启服务。
