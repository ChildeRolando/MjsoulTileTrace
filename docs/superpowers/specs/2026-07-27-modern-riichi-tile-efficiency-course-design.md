# 科学日麻牌效率课程设计

## 使命

帮助学习者在暂不考虑防守的前提下，以概率、组合与牌形结构为基础，快速判断普通四面子一雀头手牌的最优舍牌。最终目标不是背诵大量孤立口诀，而是先能精确解释结论，再把计算压缩成实战中三至五秒可执行的判断流程。

## 学习者起点

- 熟悉日麻基本规则、役与立直。
- 理解“向听数”的含义，但尚未形成逐手计算向听数的习惯。
- 已用浮牌、搭子、强化搭子、强化刻子等牌块理解牌形。
- 记得 `abcd`、`abbc`、`2334` 等牌形的部分强弱结论，但不清楚其组合计算依据。
- 目前尤其缺少对 `12`、`13` 等愚形价值，以及单张舍牌收益的统一比较方法。

## 范围

第一阶段只研究普通的“四面子一雀头”牌型：

- 门清与副露均可使用的基础牌效率原理；
- 舍牌后的向听数；
- 一次进张的有效牌种类与剩余枚数；
- 二次进张、牌形改良与进张质量；
- 重复有效牌、牌块重叠和可见牌造成的干涉；
- 从精确枚举压缩为实战决策树。

暂不涉及：

- 防守、读牌与危险度；
- 点数状况、顺位与押引；
- 打点最大化的复杂权衡；
- 七对子与国士无双的专用向听逻辑；
- 赤宝牌、宝牌造成的价值权衡，除非用于说明同效率时的平手规则。

## 核心计算模型

候选舍牌按严格的词典序比较，而不是强行合并为一个万能分数：

1. **最低向听数**：优先保留舍牌后向听数最小的方案。
2. **一次有效牌枚数**：在同向听下，计算下一次摸牌能使向听数下降的所有牌，并扣除手牌与公开区域中已知的同种牌。
3. **有效牌质量**：区分不同进张后形成的牌形、听牌类型与重复进张，避免把所有有效牌视为等价。
4. **二次进张与改良**：一次有效牌相近时，比较摸到非直接有效牌后扩大下一阶段进张的能力。
5. **最终平手规则**：再考虑好形率、牌块弹性、终局听牌质量与最低限度的打点因素。

每个结论都应能从“候选舍牌 → 新手牌状态 → 有效牌集合 → 剩余枚数 → 后续状态”还原，不使用无法解释来源的牌力常数。

## 实战压缩模型

精确模型最终压缩为以下快速流程：

1. 会不会退向听？
2. 同向听时，哪一打一次有效牌更多？
3. 数量接近时，哪一打的有效牌质量与二次改良更好？
4. 仍接近时，保留更灵活、更容易产生好形听牌的牌块。

高频结构会被整理为经过计算验证的模式库，例如浮牌等级、边张与嵌张、两面、复合搭子、`abcd`、`abbc`、`2334`。模式库是精确模型的缓存，而不是与计算脱节的口诀。

## 课程结构

课程采用短小、自包含的 HTML 单元，每课只解决一个可观察技能。

1. **第一课：有效牌与枚数**
   能对两个一向听或二向听候选舍牌，正确列出降低向听的牌种并计算剩余枚数。
2. **第二课：搭子的真实价值**
   用一次进张和改良解释 `12`、`13`、`24`、`23` 的异同，不再依赖“边张弱、嵌张弱”的模糊标签。
3. **第三课：浮牌比较**
   计算不同数牌浮牌的直接进张与改良范围，建立有来源的浮牌等级。
4. **第四课：复合牌形**
   拆解并比较 `abcd`、`abbc`、`2334`、`3456` 等重叠结构，避免重复计算有效牌。
5. **第五课：完整何切流程**
   对十四张牌枚举合理候选、保持向听、比较有效牌与后续改良。
6. **第六课以后：速度训练**
   通过限时、交错和间隔复习，把显式枚举逐步压缩为三至五秒判断。

后续课程由学习记录决定；只有在练习中表现出稳定掌握，才提高牌形复杂度。

## 每课结构

- 一个与实战直接相关的具体问题；
- 最少量的定义与计算规则；
- 一个完整的手算示例；
- 若干需要主动作答的交互题；
- 即时反馈：展示漏算、重复计算或剩余枚数扣除错误；
- 一组延迟复习题，用于下一课开头检索；
- 一张适合打印的速查表更新；
- 至少一个可信来源与可继续追问教师的提醒。

选择题的选项保持近似相同长度，避免通过排版暗示答案。练习先不限时，正确率稳定后再加入计时。

## 工作区产物

- `RESOURCES.md`：只收录经过筛选的高可信牌效率资料与实践社区。
- `lessons/NNNN-*.html`：交互课程。

## 资料原则

在制作知识性内容前，先收集能够检查算法定义与牌效率结论的可信资料。优先使用公开规则说明、成熟牌效率工具的可审查算法或文档，以及公认的现代日麻教材。无法从可靠资料确认的经验性结论应明确标注为待验证，不包装成定理。

## 验收标准

第一阶段完成时，学习者能够：

- 对普通手牌稳定判断向听数是否因舍牌改变；
- 不重不漏地列出主要候选舍牌的一次有效牌；
- 根据手牌和可见牌扣除剩余枚数；
- 解释为什么 `12` 与 `13` 在直接进张相同的情况下仍可能价值不同；
- 用相同模型解释常见复合形，而非逐个背诵；
- 在常见牌形中，于三至五秒内筛掉明显劣势舍牌，并对接近候选给出可复核的理由。

## 验证方式

- 计算题：有效牌集合和枚数均需正确；
- 对比题：必须说明比较发生在哪一层，不能只报舍牌答案；
- 迁移题：使用未在讲解示例中出现的同构牌形；
- 延迟复习：至少隔一课再次测试同一原理；
- 限时题：仅在不限时正确率达到约九成后启用。
